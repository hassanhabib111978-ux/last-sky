# LAST SKY — Project Memory v1.0

## Identity
- Name: LAST SKY
- Tagline: SURVIVE THE SWARM
- Genre: Mobile survival shooter
- Platform: Android first
- Audience: Global / English
- Perspective: Third-person
- Initial mode: Single-player
- Future direction: multiplayer-ready architecture
- Visual direction: stylized realistic / cinematic sci-fi

## Core fantasy
The player survives an abandoned city while hostile drones hunt, scan and pressure them. Survival depends on movement, combat decisions, hiding, resource management and extraction.

## Core loop
DROP → EXPLORE → LOOT → EQUIP → SURVIVE → FIGHT / HIDE / ESCAPE → UPGRADE → EXTRACT → REWARD → NEXT RUN

## Drone family
- Scout
- Attack
- Striker
- Heavy
- Commander

Difficulty should grow through survival time, drone composition, AI pressure and resource scarcity rather than only inflated health values.

## Initial weapons
- Pistol
- Assault Rifle
- Shotgun
- Anti-Drone weapon
- Later: EMP, Rocket, Rail and Experimental weapons

## Resources
Ammo, Medkit, Shield, Battery, Weapon Parts, Credits.

## First world
Abandoned City: buildings, roads, warehouses, rooftops, tunnels, open areas and hiding locations.

## Environmental storytelling
Cars, radios, laboratories, recordings, destroyed drones and locked areas should communicate the world without long exposition.

## Presentation
VFX and audio are gameplay information as well as presentation: muzzle flash, impacts, sparks, explosions, smoke, drone damage, EMP, shield hits and destruction all need readable feedback.

## Monetization direction
Free-to-play later with optional cosmetics, rewarded ads, battle pass and optional subscription. No pay-to-win.

## Current status
Foundation repository created. AI Engineer constitution and project memory are being established. Godot version and live-editor MCP integration remain to be verified before engine-specific project files are generated.
